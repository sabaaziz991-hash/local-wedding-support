Wendus Privacy Policy

Last updated: August 12, 2026

Wendus is designed as a local-first wedding planning app. Wedding event data is stored on the user's device by default.

Data the App Handles

The app can store event details, wedding period names, schedule event names, guest and household names, RSVP status, meal choices, dietary notes, accessibility notes, contact details entered by the user, seating assignments and saved seating drafts, imported venue map or floor-plan files selected by the user, venue sketch zones, scale calibration, table and item placement marks, QR pass records, check-in records, venue handoff staff packets, trusted venue peer records, local purchase pass records, export previews, local CSV import/export history, and audit history.

Data Collection

The app does not transmit event data or local purchase pass records to a developer-operated server. It does not use advertising SDKs, analytics SDKs, tracking domains, guest accounts, vendor accounts, or live cloud sync. Paid upgrades use Apple's App Store purchase system; payment card details are handled by Apple and are not stored in the app.

Camera

The camera is used only when the user opens Venue mode's QR scanner. QR payloads are opaque tokens used for local event check-in.

Local Network

Venue Handoff can use local peer-to-peer connectivity to send an encrypted, check-in-only venue packet between nearby Wendus devices with an active 3-day premium trial or One Wedding Pass. The receiver can search guests, scan or paste QR tokens, mark arrivals, and view table, meal, dietary, and accessibility notes. The receiver can return only check-in results. Wendus does not send these packets through a developer-operated server.

Local Storage and Encryption

The app stores the event snapshot locally in SQLite and encrypts the stored snapshot with Apple platform cryptography. Imported venue map files are stored as protected local sidecar files and referenced from the encrypted event snapshot by metadata. Local CSV export files and encrypted archive files use iOS file protection.

Backup and Transfer

The optional Backup & Transfer feature creates a single backup file containing the event, encrypted with a passphrase the user chooses (PBKDF2 key derivation and AES-GCM encryption using Apple's built-in cryptography). The file is created locally and leaves the device only when the user shares or saves it. Wendus cannot read the backup without the passphrase and cannot recover a lost passphrase.

Sharing and Exports

The user can create local CSV records for vendors and a master guest list CSV for spreadsheet editing. Export previews show the purpose, included fields, excluded fields, row count, and sensitive-field warning before a vendor record is created. If the user imports a CSV from Files, the app reads that selected file locally to add or update guests, households, RSVP state, meal choices, table assignments, and check-in fields. If the user imports a venue map or floor-plan PDF/image from Files, the app reads that selected file locally to create a rough, optionally scale-calibrated sketch guide with measured table and item placement. Venue Handoff transfers are intentionally started by the user and are limited to check-in-only operational data; imported venue maps and sketch files are not included in Venue Handoff packets or vendor CSV exports.

Retention

The app provides post-event closeout actions to archive the event, purge sensitive fields, keep aggregate counts, or delete local event data. Purge and aggregate-only closeout remove generated local CSV export files and imported venue map sidecar files; delete closeout removes generated local CSV export files, imported venue map sidecar files, local encrypted archive files, and local backup files.

Website Analytics

This support and privacy site is a static page and uses no analytics, cookies, or trackers. The separate marketing website at wendus.app uses Google Analytics 4 (measurement ID G-LKL2T81FPT) for aggregate website traffic measurement; that measurement never involves data from inside the app.
