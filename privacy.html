Local Wedding Privacy Policy

Last updated: June 4, 2026

Local Wedding is designed as a local-first wedding planning app. Wedding event data is stored on the user's device by default.

Data the App Handles

The app can store event details, guest and household names, RSVP status, meal choices, dietary notes, accessibility notes, contact details entered by the user, seating assignments, QR pass records, check-in records, export previews, local CSV export history, and audit history.

Data Collection

The app does not transmit event data to a developer-operated server. It does not use advertising SDKs, analytics SDKs, tracking domains, payment processing, guest accounts, vendor accounts, or live cloud sync.

Camera

The camera is used only when the user opens Venue mode's QR scanner. QR payloads are opaque tokens used for local event check-in.

Local Storage and Encryption

The app stores the event snapshot locally in SQLite and encrypts the stored snapshot with Apple platform cryptography. Local CSV export files and encrypted archive files use iOS file protection.

Sharing and Exports

The user can create local CSV records for vendors. Export previews show the purpose, included fields, excluded fields, row count, and sensitive-field warning before the record is created.

Retention

The app provides post-event closeout actions to archive the event, purge sensitive fields, keep aggregate counts, or delete local event data. Purge and aggregate-only closeout remove generated local CSV export files; delete closeout removes generated local CSV export files and local encrypted archive files.

Contact

For help with Local Wedding, use the Support URL published for the app on its App Store product page.
