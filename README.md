# Local Wedding Public Pages

These static pages are prepared for the App Store Connect Privacy Policy URL and Support URL fields.

## Files

- `privacy.html`: publish as the Privacy Policy URL.
- `support.html`: publish as the Support URL.
- `terms.html`: optional Terms page. Use Apple's standard EULA in App Store Connect unless a custom EULA is required.
- `index.html`: public landing page with links to the App Store pages.

## Required Before Submission

1. Publish this folder at a public HTTPS host.
2. Confirm the support form in `support.html` is the intended public support contact.
3. Enter the final public `privacy.html` and `support.html` URLs in App Store Connect.
4. If using a custom EULA, enter the public `terms.html` URL. Otherwise choose Apple's standard EULA.
