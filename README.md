# Wendus — Support & Privacy Pages

Official support, privacy, and terms pages for **Wendus**, the local-first wedding planning app for iPhone and iPad.

Published via GitHub Pages at:

- https://sabaaziz991-hash.github.io/local-wedding-support/ (home)
- https://sabaaziz991-hash.github.io/local-wedding-support/support.html (App Store Connect Support URL)
- https://sabaaziz991-hash.github.io/local-wedding-support/privacy.html (App Store Connect Privacy Policy URL)
- https://sabaaziz991-hash.github.io/local-wedding-support/terms.html

Support requests are handled through this repository's [issues](https://github.com/sabaaziz991-hash/local-wedding-support/issues).

The pages are static HTML with no analytics, cookies, or external assets. Content is kept in sync with `AppStoreReview/PrivacyPolicy.md` and `AppStoreReview/Support.md` in the app repository.
